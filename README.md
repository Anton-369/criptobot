# 🪙 Criptobot — Polymarket Crypto Market Engine

## 📌 Visión General
**Criptobot** es un sistema de investigación, análisis y trading automatizado enfocado en los mercados de predicción cripto de **Polymarket** (5m, 15m, 1h, 4h, Diarios y Objetivos de Precio).

## 🚀 Estructura del Repositorio
* `RESEARCH.md`: Estudio profundo de arquitectura, oráculos de Chainlink, temporalidades y estrategias de latencia.
* `src/`: Código fuente del motor de análisis y bots de trading.
* `data/`: Bases de datos SQLite y registros de señales.
